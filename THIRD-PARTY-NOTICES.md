### Bitmap-font advance widths, derived from Wine's fonts

* Owner: the Wine project. Licence: LGPL-2.1-or-later.
* Files: `render/gdifont_tables.inc`, generated by `tools/gdifont/gen_tables.py`. `tools/gdifont/gdimetrics.c` is the
  small Windows program used to measure the metrics the tables must reproduce.
* What was derived: only numbers, no glyph bitmaps. For the 96-dpi strikes of three bitmap faces (Small Fonts, MS
  Sans Serif, Courier), the generator reads each strike's header (height, ascent, internal leading, first character,
  default character) and per-character advance-width table from Wine 9.0's `smalle.fon`, `sserife.fon` and
  `coure.fon` (as shipped by Debian/Ubuntu's `fonts-wine` package, `/usr/share/wine/fonts`) and writes them out as C++
  arrays. The tables are used to lay out `maptext` the way Windows GDI does.
* Source licence: Wine is licensed under the GNU LGPL, version 2.1 or later. The generated tables are factual
  metrics extracted from those fonts; because they are derived from LGPL-licensed files, treat `gdifont_tables.inc`
  as LGPL-2.1+ material. A copy of the licence is at https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html.
  Regenerating the file is the supported way to audit it: `tools/gdifont/gen_tables.py [fontdir]`.

### Go font advance widths

* Owner: Bigelow & Holmes, with the Go Authors. Licence: BSD-3-Clause (text below).
* File: `render/gofont_adv.inc`.
* What was derived: advance widths (one character per covered code point, for each face and size from 6 to 64) of
  the Go fonts (Go, Go Bold, Go Italic, Go Bold Italic, Go Mono), computed with golang.org/x/image/font/opentype
  at full hinting. Only the numbers are included; no outlines.
* Licence: the Go fonts are by Bigelow & Holmes and are released under the same BSD-style licence as the Go project
  (BSD 3-Clause, Copyright 2009 The Go Authors); see https://go.dev/blog/go-fonts.

### Go standard-library code, ported

* Owner: The Go Authors. Licence: BSD-3-Clause (text below).
* Files: `model/gomath.h`, `render/goexp.h`; the entity-unescaping routine in `model/htmltext.cpp` (structure ported
  from the `html` package's `unescapeEntity`).
* What: C++ ports of the `math` functions the client uses (sin, cos, atan, hypot, exp and related). Bit-exact results

* Licence: BSD 3-Clause, Copyright 2009 The Go Authors. Some of the algorithms Go itself took from the Cephes
